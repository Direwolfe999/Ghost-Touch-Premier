### 🎯 The Clear Goal (The Story)

**What it is:** A **Remote Tutoring Engagement Verification** platform. 
**The Problem:** When a tutor teaches remotely, they are flying blind. They can't tell if the student is focused, stressed, or falling asleep.
**The Solution:** Ghost Touch Premier uses the Presage SDK to read the student's physiological signals (Pulse, Breathing, HRV) via webcam. The tutor sees a live dashboard of the student's *actual cognitive load*. 
**The Story:** *"Ghost Touch originally tracked a tutor's hands. Premier tracks the student's biology to verify that learning is actually happening."*

---

### 🛠️ What We Are Using vs. What We Are NOT Using

**✅ WE ARE USING:**
*   **Electron:** To run it as a desktop app (fastest for camera access).
*   **React (Vite):** For the UI (fast, component-based).
*   **Node.js + Express:** A tiny local backend just to pass messages between the Tutor window and Student window.
*   **Socket.io:** For live, real-time updates between Tutor and Student.
*   **Presage SDK:** For the biometric data.
*   **Vanilla CSS:** For the Ghost Touch dark/neon aesthetic.

**❌ WE ARE NOT USING:**
*   **Django or Postgres:** Too heavy. We will store session data in Node's memory.
*   **Flutter:** We are using React for this hackathon.
*   **MediaPipe/Hand-tracking:** That was the old project. We are focusing *only* on Presage.
*   **Complex Auth (JWT/Bcrypt):** We will use a simple mock login (just store the name and role in React state).

To avoid it looking "halved," we build a clean architecture. We are merging the Electron app with React.

```text

        └── SessionReport.jsx     # The final summary
```

---

### 🗺️ The 5 Screens (The Complete Loop)

1.  **Auth Screen:** Beautiful dark mode. "I am a Tutor" / "I am a Student".
2.  **Tutor Setup:** Tutor clicks "Start Session", gets a 4-digit code (e.g., `GH-44`).
3.  **Student Join & Consent:** Student enters code. Sees mandatory Presage Consent Modal. Camera turns on.
4.  **Live Dashboard (Tutor):** Shows the student's tile. Live pulse/HRV. If they get stressed, the tile glows orange.
5.  **Session Report:** Tutor clicks "End Session". Shows average focus time and a chart.
